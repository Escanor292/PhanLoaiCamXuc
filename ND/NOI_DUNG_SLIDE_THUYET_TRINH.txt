SLIDE 8: GIỚI THIỆU ĐỀ TÀI
--------------------------------------------------------------------------------

1. TÊN ĐỀ TÀI:
HỆ THỐNG PHÂN LOẠI CẢM XÚC ĐA NHÃN CHO TIẾNG VIỆT
SỬ DỤNG PHOBERT HYBRID

2. LÝ DO CHỌN ĐỀ TÀI:

❓ VẤN ĐỀ:
• Phân tích cảm xúc là bài toán quan trọng trong NLP
• Cảm xúc con người phức tạp, thường có nhiều cảm xúc cùng lúc
• Các hệ thống hiện tại chỉ phân loại đơn nhãn (1 cảm xúc)
• Thiếu hệ thống phân loại đa nhãn cho tiếng Việt

💡 GIẢI PHÁP:
• Xây dựng hệ thống phân loại ĐA NHÃN (multi-label)
• Sử dụng PhoBERT - model BERT cho tiếng Việt
• Kết hợp BiLSTM + Attention để tăng độ chính xác
• Hỗ trợ 16 loại cảm xúc đồng thời

3. BỐI CẢNH:

Ứng dụng thực tế:
✅ Phân tích phản hồi khách hàng trên e-commerce
✅ Chatbot thông minh
✅ Theo dõi sức khỏe tinh thần
✅ Phân tích mạng xã hội

4. KHẢO SÁT:

Các phương pháp hiện có:
• Keyword matching: Đơn giản nhưng không chính xác
• Rule-based: Phức tạp, khó bảo trì
• BERT multilingual: Không tối ưu cho tiếng Việt
• PhoBERT: Tốt nhất cho tiếng Việt

5. CÁCH GIẢI QUYẾT:

Kiến trúc PhoBERT Hybrid:
┌─────────────────────────────────────┐
│ Input Text                          │
│         ↓                           │
│ PhoBERT Encoder (768-dim)           │
│         ↓                           │
│ BiLSTM (256 units)                  │
│         ↓                           │
│ Self-Attention                      │
│         ↓                           │
│ Classification (16 emotions)        │
│         ↓                           │
│ Output: Multi-label predictions     │
└─────────────────────────────────────┘

2. THUẬT TOÁN TRAINING:

```
Algorithm: Train PhoBERT Hybrid Model

Input: 
  - Training data: X_train, y_train
  - Validation data: X_val, y_val
  - Hyperparameters: epochs, batch_size, learning_rate

Output:
  - Trained model with best validation F1-score

Steps:
1. Load pre-trained PhoBERT from Hugging Face
2. Initialize BiLSTM, Attention, Classification layers
3. Set optimizer = AdamW(lr=learning_rate)
4. Set loss_function = BCEWithLogitsLoss()
5. best_f1 = 0

6. For epoch in range(epochs):
   a. Training phase:
      - For each batch in train_loader:
        * Forward pass: predictions = model(batch)
        * Calculate loss = loss_function(predictions, labels)
        * Backward pass: loss.backward()
        * Update weights: optimizer.step()
   
   b. Validation phase:
      - For each batch in val_loader:
        * predictions = model(batch)
        * Calculate metrics: F1, precision, recall
      
   c. If val_f1 > best_f1:
        * best_f1 = val_f1
        * Save model checkpoint
        * Upload to Hugging Face Hub

7. Return best model
```

📄 model.py - PhoBERT Hybrid Architecture:
```python
class PhoBERTEmotionClassifier(nn.Module):
    def __init__(self, num_labels=16, lstm_hidden=256, dropout=0.3):
        super().__init__()
        # Load pre-trained PhoBERT
        self.phobert = AutoModel.from_pretrained("vinai/phobert-base")
        
        # BiLSTM layer
        self.bilstm = nn.LSTM(
            input_size=768,
            hidden_size=lstm_hidden,
            num_layers=1,
            bidirectional=True,
            batch_first=True
        )
        
        # Attention mechanism
        self.attention = nn.Linear(lstm_hidden * 2, 1)
        
        # Classification head
        self.dropout = nn.Dropout(dropout)
        self.classifier = nn.Linear(lstm_hidden * 2, num_labels)
    
    def forward(self, input_ids, attention_mask):
        # PhoBERT encoding
        outputs = self.phobert(input_ids, attention_mask)
        sequence_output = outputs.last_hidden_state
        
        # BiLSTM
        lstm_out, _ = self.bilstm(sequence_output)
        
        # Attention
        attention_weights = torch.softmax(
            self.attention(lstm_out), dim=1
        )
        context_vector = torch.sum(
            attention_weights * lstm_out, dim=1
        )
        
        # Classification
        output = self.dropout(context_vector)
        logits = self.classifier(output)
        
        return logits
```

📄 train_simple.py - Training Script:
```python
def train_model():
    # Load data
    df = merge_all_csv_files()
    train_loader, val_loader, test_loader = prepare_dataloaders(df)
    
    # Initialize model
    model = PhoBERTEmotionClassifier()
    optimizer = AdamW(model.parameters(), lr=1e-5)
    criterion = nn.BCEWithLogitsLoss()
    
    # Training loop
    best_f1 = 0
    for epoch in range(EPOCHS):
        # Train
        model.train()
        for batch in train_loader:
            optimizer.zero_grad()
            logits = model(batch['input_ids'], batch['attention_mask'])
            loss = criterion(logits, batch['labels'])
            loss.backward()
            optimizer.step()
        
        # Validate
        val_f1 = evaluate(model, val_loader)
        
        # Save best model
        if val_f1 > best_f1:
            best_f1 = val_f1
            save_model(model)
            upload_to_huggingface(model)
    
    return model
```

📄 api_server.py - Flask API:
```python
from flask import Flask, request, jsonify

app = Flask(__name__)
model = load_best_model()

@app.route('/predict', methods=['POST'])
def predict():
    data = request.json
    text = data['text']
    
    # Preprocess
    inputs = tokenizer(text, return_tensors='pt')
    
    # Predict
    with torch.no_grad():
        logits = model(**inputs)
        probs = torch.sigmoid(logits)
    
    # Format output
    emotions = []
    for i, prob in enumerate(probs[0]):
        if prob > 0.5:
            emotions.append({
                'emotion': EMOTION_LABELS[i],
                'confidence': float(prob)
            })
    
    return jsonify({'emotions': emotions})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

📊 PHẦN B: GIẢI THÍCH CÁC METRICS

1. MICRO F1-SCORE: 0.7057 (70.57%) ✅

Công thức:
Micro F1 = 2 × (Precision × Recall) / (Precision + Recall)
• Precision = TP_total / (TP_total + FP_total)
• Recall = TP_total / (TP_total + FN_total)

Ý nghĩa:
• Đo độ chính xác TỔNG THỂ trên tất cả predictions
• Labels nhiều samples có trọng số cao hơn
• QUAN TRỌNG NHẤT cho multi-label classification
• 0.7057 ≥ 0.70 → ✅ ĐẠT MỤC TIÊU!

Ví dụ thực tế:
• 1000 predictions → ~706 đúng, 294 sai
• Accuracy tổng thể: 70.57%

2. MACRO F1-SCORE: 0.6837 (68.37%) ✅

Công thức:
Macro F1 = (F1_joy + F1_sadness + ... + F1_excited) / 16
• Mỗi emotion có trọng số BẰNG NHAU

Ý nghĩa:
• Trung bình F1 của 16 cảm xúc
• Không phụ thuộc số lượng samples
• Đảm bảo không bỏ sót cảm xúc nào
• 0.6837 ≥ 0.65 → ✅ VƯỢT 5.2%!

So sánh:
• Micro F1 (0.7057) > Macro F1 (0.6837)
• → Model tốt hơn với cảm xúc phổ biến
• Một số cảm xúc ít (proud, trust) có F1 thấp

3. HAMMING LOSS: 0.1105 (11.05%) ✅

Công thức:
Hamming Loss = (Số labels SAI) / (Tổng số labels)
             = (1/N) × Σ|y_true XOR y_pred|

Ý nghĩa:
• Tỷ lệ labels dự đoán SAI (càng thấp càng tốt)
• 0.1105 < 0.15 → ✅ ĐẠT MỤC TIÊU!
• Chỉ 11.05% sai → 88.95% CHÍNH XÁC!

Ví dụ:
Input: "Tôi vui nhưng lo"
True:  [joy=1, worried=1, others=0]
Pred:  [joy=1, worried=1, others=0]
→ Hamming Loss = 0/16 = 0 (perfect!)

4. TRAIN-VAL GAP: 0.0072 ✅

Train Loss: 0.4666
Val Loss:   0.4738
Gap:        0.0072

Ý nghĩa:
• Gap < 0.01 → ✅ KHÔNG OVERFIT!
• Model generalize tốt
• Không học thuộc lòng training data

📊 PHẦN C: GIẢI THÍCH HYPERPARAMETERS

1. LEARNING RATE: 1e-5 (0.00001)

Ý nghĩa:
• Tốc độ học của model (bước nhảy update weights)
• 1e-5 = rất nhỏ → Học chậm nhưng ổn định

Tại sao 1e-5?
• PhoBERT đã pre-trained → Chỉ fine-tune nhẹ
• 1e-3 (lớn) → Phá hỏng kiến thức
• 1e-6 (nhỏ) → Học quá chậm
• ✅ 1e-5 là SWEET SPOT cho BERT

2. BATCH SIZE: 16

Ý nghĩa:
• Số samples xử lý cùng lúc
• 16 văn bản/lần update weights

Tại sao 16?
• Cân bằng tốc độ và bộ nhớ
• Batch 8 → Chậm, generalize tốt
• Batch 32/64 → Nhanh, cần nhiều RAM
• ✅ 16 là OPTIMAL cho laptop/desktop

3. EPOCHS: 5

Ý nghĩa:
• Số lần model đi qua TOÀN BỘ data
• 5 epochs = Mỗi sample thấy 5 lần

Tại sao 5?
• Transfer Learning → Không cần nhiều
• Epoch 1-3: Học nhanh
• Epoch 4-5: Tinh chỉnh
• Epoch > 5: Có thể overfit
• ✅ 5 epochs ĐỦ với 10,930 mẫu

Training time: ~60 phút/epoch × 5 = ~5 giờ

4. MAX LENGTH: 100 tokens

Ý nghĩa:
• Độ dài tối đa input
• Văn bản dài hơn bị cắt

Tại sao 100?
• BERT standard: 512 tokens
• Comments tiếng Việt: ~50-100 tokens
• 100 tokens đủ cho 95% samples
• ✅ Tăng tốc 5x, giảm RAM 5x

5. LSTM HIDDEN SIZE: 256

Ý nghĩa:
• Số units trong BiLSTM
• Bidirectional → Output = 512-dim

Tại sao 256?
• PhoBERT: 768-dim
• LSTM 256 → Compress 768 → 512
• Giữ đủ thông tin, không quá phức tạp
• ✅ 256 là BALANCED

6. DROPOUT RATE: 0.3

Ý nghĩa:
• Tỷ lệ neurons "tắt" khi training
• 0.3 = 30% neurons tắt/iteration

Tại sao 0.3?
• Dropout chống overfit
• 0.1-0.2: Ít, có thể overfit
• 0.4-0.5: Nhiều, có thể underfit
• ✅ 0.3 là STANDARD cho BERT
